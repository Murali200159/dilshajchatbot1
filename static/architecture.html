Step 1
🖱️ User Sends Message
Browser POSTs to /api/v1/chatbot/chat/stream. Cache checked first — hit returns instantly.
Step 2
🧠 Agent Starts
LangGraph _chat node runs. Detects if greeting → skip heavy services.
Step 3
📄 Proactive RAG
FAISS searched with user query. Top-3 company doc chunks injected into system prompt — no extra LLM call needed.
Step 4
🧩 Memory Search
Qdrant searched for past user context. Results appended to system prompt as "User History".
Step 5
🦙 Single LLM Call
llama3.1 called once with full context. If it calls user_payment_tool → MongoDB queried → second LLM call for answer.
Step 6
📡 Stream Response
Tokens streamed word-by-word via SSE. Browser displays them live. Response cached for 5 minutes.
